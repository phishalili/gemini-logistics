# Gemini Logistics

Aplikacioni i GEMINI Cars & Logistics: çmimet, porositë, udhëtimet, veturat në kthim dhe ngarkimi 3D.

- Hape në telefon: https://phishalili.github.io/gemini-logistics/
- Çmimet e naftës përditësohen vetë çdo të martë (`.github/workflows/prices.yml` → `prices.json`).
- Të dhënat (porositë, udhëtimet) ruhen vetëm në telefonin ku përdoret aplikacioni.
